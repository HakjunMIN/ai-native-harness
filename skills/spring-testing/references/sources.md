# Spring testing live sources

Follow the [live-documentation protocol](../../sdlc/references/live-documentation.md).
Fetch only relevant references and select the project's installed version,
including its JUnit major; an upstream current release is not an upgrade request.

| Topic | Official URL to fetch | Verify |
|---|---|---|
| Boot test support | [Spring Boot testing](https://docs.spring.io/spring-boot/reference/testing/index.html) | Test slices, annotations, packages and dependencies |
| Framework testing | [Spring testing](https://docs.spring.io/spring-framework/reference/testing.html) | Context, HTTP and security test boundaries |
| JUnit | [JUnit guide](https://docs.junit.org/current/user-guide/) | Version-specific lifecycle, assertions and discovery |
| HTTP stubs | [WireMock docs](https://wiremock.org/docs/) | Matching, delays, errors and integration |
| Containers | [Testcontainers Java](https://java.testcontainers.org/) | Lifecycle, modules and runtime prerequisites |
| API assertions | [REST Assured guide](https://github.com/rest-assured/rest-assured/wiki/Usage) | Installed API, serialization and assertions |

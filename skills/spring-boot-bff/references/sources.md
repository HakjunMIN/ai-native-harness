# Spring BFF live sources

Follow the [live-documentation protocol](../../sdlc/references/live-documentation.md).
Fetch relevant URLs at task time; resolve version navigation before using APIs.

| Topic | Official URL to fetch | Verify for installed versions |
|---|---|---|
| Boot | [Spring Boot reference](https://docs.spring.io/spring-boot/reference/) | Configuration, dependencies and supported runtime |
| HTTP client and errors | [Spring Framework reference](https://docs.spring.io/spring-framework/reference/) | WebClient, cancellation, MVC/WebFlux and ProblemDetail |
| Identity | [Spring Security reference](https://docs.spring.io/spring-security/reference/) | Authentication context and authorization integration |
| Build | [Gradle user guide](https://docs.gradle.org/current/userguide/userguide.html) | Existing task and plugin compatibility |

Fetch upstream query contracts through [SigNoz sources](../../signoz-query-service/references/sources.md)
or [Prometheus sources](../../prometheus-query-api/references/sources.md), as applicable.
